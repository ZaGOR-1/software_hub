Key lifecycle guarantees
------------------------
- A file cannot publish unless its parents are eligible and persisted signature,
  scanner state, physical size and SHA-256 all pass.
- Filesystem moves precede short DB transactions and are compensated on failure.
- Disable/archive never remove bytes.
- Published files must be disabled or archived before deletion.
- Metadata-only deletion explicitly preserves an orphan for reconciliation.
- Permanent deletion stages bytes privately before metadata commit and restores
  them when the DB transaction fails.
- A post-commit unlink failure leaves a private artifact and raises an
  operator-visible critical storage error instead of hiding data loss.
