Security properties
-------------------
- app, nginx and optional certbot use UID/GID 10001 by default
- app/nginx read-only root filesystem
- cap_drop ALL and no-new-privileges
- no app host port, host network, privileged mode or Docker socket
- fixed trusted proxy IP on internal backend network
- Nginx permanent software and TLS mounts read-only
- production admin policy defaults to deny all
- Nginx owns TLS, security headers, static, limits and X-Accel delivery
- application image receives no source-wide COPY or production secrets
