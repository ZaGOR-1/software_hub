Security properties
-------------------
- General discovery is limited to published + public software.
- Unlisted and archived entries require an exact slug.
- Private entries require an active administrator session.
- Disabled entries remain inaccessible to all public-page callers.
- Public templates receive immutable view models, not ORM entities.
- Storage names, physical paths, admin notes and scanner details are excluded.
- Draft/disabled releases and all non-published files are excluded.
- Anonymous file lists expose only public files.
- Search length is bounded and SQL LIKE wildcards are escaped.
- Hidden categories and private-only tags are not public facets.
- Public popularity excludes private and unlisted file counters.
- Jinja autoescape remains enabled; no user content uses |safe.
- Private/unlisted direct pages emit noindex, nofollow.
